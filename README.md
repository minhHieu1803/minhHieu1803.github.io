# minhhieu1803.github.io

Personal portfolio of **Pham Minh Hieu**, fresher Python backend developer and M.Sc. IT candidate at HUTECH.

Live site: https://minhhieu1803.github.io/ (English) · https://minhhieu1803.github.io/vi/ (Vietnamese)

## What's inside

- A case study of my master's thesis: a FastAPI service that runs a video emotion-recognition pipeline as
  background jobs, with the architecture, engineering decisions and benchmark results.
- Skills, education and contact details.
- My CV in English and Vietnamese (`cv/`).
- English / Vietnamese switch, light and dark themes, works on phones.

## Stack

Plain HTML, CSS and JavaScript. No framework and no build step. Fonts from Google Fonts.

```
index.html          the page (English at /); holds both languages, shown by the lang attribute
vi/index.html       the Vietnamese page at /vi/, generated by tools/make_vi.py
assets/css/style.css
assets/js/main.js   language links and copy-to-clipboard
assets/favicon.svg
cv/                 CV PDFs
tools/make_vi.py    rebuilds vi/index.html from index.html
netlify.toml        settings for an optional Netlify deploy
```

After editing `index.html`, run `python tools/make_vi.py` so the Vietnamese page stays in sync.

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000 and http://localhost:8000/vi/
```

## Deploy

GitHub Pages publishes the `main` branch of this repository automatically.

The same repository can also be deployed on Netlify (import the repo, no build command, publish
directory `.`). Netlify redeploys on every push to `main`.
